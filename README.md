# 家谱树（jiashu Family Tree）

> 单文件离线家族树 · 树形 / 网图双视图 · 代际自动分层 · 中文本土化称谓 · 可拖拽布局 · 移动端适配。

纯前端、零依赖、不联网：全部数据存浏览器 `localStorage`，不经过任何服务器。打开 `family-tree-v3.html` 即可使用，适合记录并可视化一个家族的多代血缘与婚姻关系。

## 功能特性

-   **树形视图**：按代自动分层，左侧带「第 N 代」标签与交替浅色行背景带；亲子连线按「父母组」分配家族色，重叠处不同家庭用不同色可一眼区分。
-   **网图视图**：力导向关系图，可手动把任意节点拖到自己想要的位置（自动记忆，刷新不丢）；拖动时附近重叠的成员会沿径向推开，并做一次成对分离（同 d3-force 的 `forceCollide` 思路），被推开的成员不会彼此再叠上。
-   **同代微调**：树形视图下可左右拖动成员卡片，仅在当前世代内水平移动；让位采用**确定性一维区间打包**（Observable Plot dodge / Force-Scan 思路）——拖动者钉在原地、其余成员只朝远离它的单方向最小位移让位，不会两侧互推，也不会挤成一团。
-   **成员编辑**：新增根成员 / 子女 / 配偶 / 父亲 / 母亲 / 继父 / 继母；继亲、配偶等可选项改为可搜索多选（人数再多也不堆叠）。
-   **称谓查询**：接入 relationship.js 计算任意两人的中文本土称谓，A、B 人物均支持搜索选择。
-   **关系连线语义**：网图——亲子＝绿色箭头线（长辈→晚辈，性别中立色，不用男性蓝），配偶＝灰实线，继亲＝灰虚线；树形——亲子按「父母组」家族色（见上），远嫁 / 远娶（被配偶吸走的成员）以家庭色虚线弧＋两端圆点连回其亲生父母总线，避免长横线横穿全图造成的视觉误会。
-   **连线贴边裁剪**：网图连线一律止于「卡片外扩后的矩形」边界而非卡片中心（同 ggraph 的 `start_cap` / `end_cap`、ggnet2 的 `arrow.gap`），箭头尖端恒在卡片外 8px、不会被节点盖住；多个父母也从不同方位抵达，不会汇聚到节点同一点。
-   **导出**：一键导出完整树为 PNG（2× 高清）或 SVG；数据可导出 / 导入 JSON 做备份。
-   **移动端适配**：窄屏弹窗改为底部抽屉、表格横向滚动、缩放按钮加大；单指平移画布、双指捏合缩放、单指拖动节点。

## 系统要求

-   任意现代浏览器（Chrome / Edge / Safari，含移动端）。
-   无需联网、无需后端、无需安装任何运行时。

## 构建命令

```bat
:: 进入构建目录
cd tools/family-tree-builder

:: 生成根目录的 family-tree-v3.html（单文件离线交付物）
python build.py --v3
```

> 构建仅把 `engine.js` + `app-v3.js` + `template-v3.html` 注入打包成单文件 HTML。日常使用直接双击 `family-tree-v3.html` 即可，无需构建；只有改源码后才需要重新构建。

## 使用说明对照表

| 操作 | 说明 |
| --- | --- |
| 新增成员 | 点卡片 → 「＋ 添加子女 / 配偶 / 父亲 / 母亲 / 继父 / 继母」 |
| 编辑 / 删除 | 点卡片 → 「✎ 编辑资料 / ✕ 删除成员」 |
| 切换视图 | 卡片头部「树形 / 网图」切换按钮 |
| 网图拖节点 | 在网图视图直接按住节点拖到任意位置（落点自动记忆，刷新保留） |
| 树形同代微调 | 树形视图按住成员卡片左右拖动，仅在本代内水平移动 |
| 重新布局 | 「重新布局」按钮：重算力导向并清除所有手动调整 |
| 称谓查询 | 选人物 A、人物 B → 「查称呼」 |
| 导出图片 | 数据卡「导出图片 PNG / 导出 SVG」导出完整树 |
| 数据备份 | 数据卡「导出 JSON」；「导入 JSON」可恢复覆盖 |
| 缩放 / 平移 | 滚轮缩放、拖空白处平移；移动端单指平移、双指捏合缩放 |

## 技术栈

-   **前端**：原生 HTML / CSS / JavaScript（单文件，离线零依赖）
-   **称谓引擎**：[relationship.js](https://github.com/mumuy/relationship) v1.2.9（中文本土称谓，本地 vendored）
-   **构建**：Python 脚本拼接打包（`build.py`）

## 目录结构

```
├── family-tree-v3.html          # 单文件交付物（双击即用，构建产物）
├── tools/family-tree-builder/
│   ├── build.py                 # 构建脚本（python build.py --v3）
│   ├── template-v3.html         # 页面骨架与样式
│   ├── app-v3.js                # 全部交互与渲染逻辑
│   ├── engine.js                # 第三方依赖（relationship.js 等，vendored）
│   └── node_modules/            # 仅本地开发验证用（playwright，git 忽略）
├── family-tree-2026-10-28.json  # 示例 / 个人数据（git 忽略，不公开）
└── README.md
```

> 个人数据（`family-tree-*.json`）与开发临时文件（`.tmp/`、`.workbuddy/`）默认不进入版本库，见 `.gitignore`。
